# filament-kit 0.5.1

Upgrade the server with `sudo filament-kit update`.

## What's new

### The phone web app and the setup page

- **The phone web app is served by the kit server itself** at `https://<computer name>.local:8710/intake`, and it pairs
  from inside the server.
- **The setup page answers to local DNS names of the server** (a one-word name, `.local`, `.lan`, `.home.arpa`, and the
  search domain of your resolver), and to names you add in **Settings**.
- **The Printers tab links the live printer view** of the phone web app, for loading spools and the camera.
- **Collect a report** is on the setup page's Printers tab, and the page lists and downloads the reports it kept.

### Printer reports

`sudo filament-kit printer report <serial>` makes one file to attach to an issue about a printer the kit does not know,
or whose slot mapping failed. It can now be made from every interface: the setup page, the phone web app, the Android
app's printer screen and the command line. A printer that is offline still gets a report, built from the records the kit
saved. The command line asks the running server, which holds the printer, and waits for the printer to connect; it stops
early only for a wrong access code, a changed certificate or an unconfigured printer. `printer map` waits the same way.

### Android app

- **The version sits under the title** on the home and pairing screens.
- **Collect a report** is on the printer screen and shares the file through the phone's share sheet.
- **Settings opens the server's setup page.**

### The intake panel on the ESP32-C3

- **The panel is now an ESP32-C3** with speech through a MAX98357 amplifier, and the station flashes the panel
  firmware that ships with each release. It flashes only a panel with **older** firmware, never down. A panel on an
  **ESP8266** (a Wemos D1 mini, firmware 9 and older) is used as it is and is never flashed.
- **An optional PN532 reader on the panel's I2C bus** works beside the USB reader. The same tag seen by both within
  2 seconds is one tap.
- **A blank C3 board** is flashed once with `sudo filament-kit station flash-panel`.
- Build guides, wiring, parts and enclosures for the station's devices are now in the public
  [filament-kit-hardware](https://github.com/thompsonfabco/filament-kit-hardware) repository, and the kit's docs link
  to it. The intake station's scale is the **DYMO M10**; other DYMO USB postal scales the kit detects also work.

### Updating and restoring

- **Follow nightly builds.** `sudo filament-kit update --channel nightly` (or the switch on the setup page's Updates
  tab) follows the nightly prereleases, which are untested and unsigned; the setup page says so each time you switch it on.
  `sudo filament-kit update --channel stable` goes back to the signed releases and replaces any nightly. A nightly is
  never kept as a rollback target. The switch is off by default.
- **Restore is stricter.** A restore never takes file owners or modes from the zip, and restores only the upload you
  confirmed. The setup helper writes only to places owned by root.
- **The camera relay** can only be used by the server's own user.

## Upgrading

Run `sudo filament-kit update`. Going back (`sudo filament-kit update --rollback`) returns to the previous signed
release.
