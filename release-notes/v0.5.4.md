# filament-kit 0.5.4

Upgrade the server with `sudo filament-kit update`.

A maintenance release on 0.5.3 with two fixes. Nothing else changed.

## Fixes

- **The local label reader's commands now work from the command line.** `sudo filament-kit local-intake install`,
  `remove`, `token` and `plan` run with the rights they need, the same way `reader setup` does, instead of failing
  partway when started as your own user.
- **Approving a pairing request can no longer hang the kit.** When a request ran out, or was answered twice, at the
  moment a Printer Station or other device was approved, the pairing page could stop answering until the server was
  restarted. It now answers "no such request (it may have run out)" and carries on.

## Upgrading

Run `sudo filament-kit update`. Going back (`sudo filament-kit update --rollback`) returns to the previous signed
release. Nothing needs changing by hand.
