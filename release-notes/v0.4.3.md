# filament-kit 0.4.3

Upgrade the server with `sudo filament-kit update`.

## What's new

### A tabbed setup page

The setup page (`https://<computer name>.local:8710/setup`) now has tabs: **Overview**, **Modules**, **Printers**,
**Devices**, **Settings** and **Updates**.

- **Overview** shows the version, what the checks of `sudo filament-kit status` say, and a **Still to do** list. Addresses
  and serial numbers stay hidden until you give the setup code and tap **Show addresses**.
- **Modules** has ready-made modes, with what each will switch on, and a live log while the change is applied.
- **Updates** shows the latest release and its notes. **Check now** (with the setup code), **Update** and **Roll back**
  work from the page. The page waits through the restart and reloads itself when the update is done.

### Smaller changes

- **Undo** refuses a spool that was not there when the print ended.
- **Turning a module off** says everything it takes with it, and a terminal offers what one needs.
- **A signed filament library with newer rules** is used without what this kit cannot read, and says how much.
- **Klipper printer pack.** It offers a restart of Moonraker after editing `moonraker.conf`, only while the printer is
  idle, and asks for the Spoolman address and says so when it has none.

## Upgrading

Run `sudo filament-kit update`. Going back to the previous version (`sudo filament-kit update --rollback`) leaves the
setup page's new job unit on disk, unused.
