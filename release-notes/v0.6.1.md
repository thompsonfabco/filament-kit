# filament-kit 0.6.1 (pre-release)

**This is a pre-release**, the second look at the redesigned interfaces. It is not the newest release:
`sudo filament-kit update` does not offer it, and a kit on 0.5.4 stays on 0.5.4 until you install this one by hand.
A few places are not finished (listed below). Install it if you want to try the new look; stay on 0.5.4 if you want
the settled one.

## What is new since 0.6.0

### The phone web app is rebuilt

- **Add spools:** find a filament you already have or read the label photos, check each spool card with the Label
  Reader's confidence marks, Preview, then Add. An unfinished add is kept as a draft in that browser.
- **Spools:** the last tag read, a search that remembers Sealed only, and a spool sheet to link a tag and open the
  spool, update its weight, move it (with Undo), mark it empty or load it into a printer. Nothing is written that was
  not previewed.
- **Printers:** the printer list and one printer's page with its status, slots, filament used, slot mapping and
  settings.
- **Recently added:** each addition with its badges, where it came from and when; open one for its photos and
  fields, correct it by hand or ask the Label Reader, and undo a revision.
- **Slicer presets:** build the presets and see the result in place; add a new filament to a line or start a new
  line; Updates and Restore work as on the Hub page.
- **Home screen and offline:** the Add to Home Screen sheet lists the three iPhone steps (other browsers offer their
  own install). The app opens without the Hub; when the Hub does not answer it shows an Offline chip and a banner,
  tries again every 10 s, keeps the last data with "Last update <age>: the Hub did not answer.", greys what needs
  the Hub with "Needs the Hub.", and says when it is connected again.

### Themes

- **A Theme choice** on the Hub page (Settings > Appearance), in the phone web app (Settings) and in the Android app
  (Settings > Appearance). The choice is kept on that device; a device that has not chosen shows the Hub's theme for
  new devices.
- **Four themes:** Console (dense and technical, as in 0.6.0), Workbench (calm cards, a labelled side list on wide
  screens), Palette (colourful and roomy, a row of pills under the top bar, lists as tiles) and Panes (a list of
  sections with the page beside it, lists as plain rows). Each has a light and a dark side.
- The Android app has all four. Its screens and routes are the same in every theme, and details open as their own
  screen.

### The command line speaks one way

- **One vocabulary:** every command reports with the same state words, and a failure is `Error: ...` with a
  `Fix: ...` line. Waits longer than 2 seconds show progress; each command ends with a documented exit code;
  `--plain`, `--color` and `NO_COLOR` control the look for screen readers and pipes.
- **Destructive commands ask first** (forgetting a printer, unpairing a device, flashing a board, updating, rolling
  back, removing the kit). **Scripts need `--yes` from this version on:** without a terminal and without `--yes`
  such a command stops with exit code 2 and says so.
- **`--json` and `--quiet`** on every command that prints data or a result.
- **New command names** that match the Hub page: `printer`, `recent`, `devices`, `pair`, `presets`, `features`,
  `weigh-station`, `tag-reader`, `label-reader`, `catalog`, `config show` and `config set`. The old spellings still
  work; `filament-kit help aliases` lists them and `filament-kit help` prints the whole table.
- **Menus with one set of keys:** `filament-kit config` is the Hub page's Settings in the same groups; changes wait
  until `s` saves them. Printers and Features have their own screens.

### The Android app

- **Slicer presets screen:** the build status, a button to build now, the filaments without a preset line (add to a line
  or start one, with an optional Orca Slicer parent) and the product lines with Change parent.
- The last texts are whole sentences, and Replace this spool's tag is offered when the spool already has a tag.

### Documents

- The README, the user guide and the install guides use the new names (Hub, Hub page, web app, app, Features, Weigh
  Station, Tag Reader, Label Reader, Filament Catalog, Slicer presets, Slicer Sync) and show the commands in their
  new spellings. The user guide's command table is the one `filament-kit help` prints.

## Not finished

- **Palette and Panes on the Hub page:** a printer's or a preset line's details still open in place under the row
  or tile, not in a sheet (Palette) or in the pane (Panes).
- **Guide pages** that walk through the phone web app and the Android home screen still describe 0.5.4's screens.
- The product is still called filament-kit on every screen and in every command.

## Install it over 0.5.4 or 0.6.0

A pre-release is not the newest release, so `filament-kit update` does not find it. Install it by version, on the Ubuntu
computer:

```
curl -fsSLO https://github.com/thompsonfabco/filament-kit/releases/latest/download/get.sh && sudo bash get.sh --version 0.6.1
```

It keeps your spools, settings, key and paired phones. After it, `filament-kit update` says you are up to date until a newer release than this one comes out.

## Going back to 0.5.4

Run the same command with the earlier version:

```
sudo bash get.sh --version 0.5.4
```

Your spools and settings stay.
