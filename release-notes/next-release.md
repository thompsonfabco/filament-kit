# filament-kit: next release

## What's new

- **Android app.** Pairing by hand no longer asks you to type two groups of the fingerprint. The app shows the
  server's address and its full fingerprint: compare it with the one on the server, then tap **It matches** or
  **It does not match**. If you would rather not be asked, **Settings** has a switch, **Skip the fingerprint check for
  new servers**, off by default. A scanned QR code is checked either way.
  After **It does not match**, the app says something else may be answering at that address. An update Android refuses
  because of its signature now says so as a plain fact, with a plain **Try again**.
