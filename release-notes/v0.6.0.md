# filament-kit 0.6.0 (pre-release)

**This is a pre-release.** It is the first look at the redesigned interfaces, and it is not the newest release:
`sudo filament-kit update` does not offer it, and a kit on 0.5.4 stays on 0.5.4 until you install this one by hand.
Some places are not finished and still look like 0.5.4. Install it if you want to try the new look; stay on 0.5.4 if you
want the settled one.

## What is new

### The Hub page (the setup page) is on the new look

- **One look.** The page uses the shared colours, sizes, buttons and texts (the Console theme), the same as the other
  interfaces.
- **Light, dark or system.** A switch in the header picks Light, Dark or System (the default); the choice is kept in that
  browser.
- **A new shell.** A top bar and navigation: a side list on wide screens, and on a phone a bottom bar with a More sheet for
  the other sections.
- **A lock chip** in the header shows whether the page is unlocked and opens the unlock dialog. A right setup code costs no
  try; a wrong one says how many tries are left.
- **Dialogs replace the browser's own confirm and prompt boxes.** The result of a button appears beside it, with a short toast
  when something finishes, and long jobs show a job strip with the step they are on ("Step 2 of 3"), including when the kit
  is restarting or not answering.
- **The same loading, empty, error and switched-off pages everywhere.**
- **Sections:** Overview (summary tiles for printers, Tag Readers and recent additions, with a badge for what needs a look), Features, Slicer presets, Updates and Logs are in the new look. Logs wrap at every width instead of scrolling sideways.
- **Printers (setup page):** each printer shows its state, with how many are connected or offline. You can test the connection, use a detected printer, dismiss it, see its slot mapping and collect a report. Saved reports show once the page is unlocked. You can also add a printer from the page: it can scan the Hub's own network for Klipper printers, and it offers the Klipper add-on's install commands to copy.
- **Setup names:** `hub`, `weigh-station` and `hub-with-weigh-station` are accepted beside `server`, `station` and
  `all-in-one`, and `--hub` beside `--server` in `filament-kit modules set` and `modules enable`. What the kit stores does
  not change.
- **QR codes are drawn by the Hub itself** (the pairing code and the phone web app's address on the Hub page, and in the
  terminal), so the `qrencode` package is no longer needed.
- **Smaller changes:** every printer's state comes in one read; a reader that gives no per-field numbers
  is shown as not rated instead of as sure; an address you enter for the Hub can be tested before it is saved; a settings
  group saves at once and shows the last backup time.

### The phone web app and the Android app

- The phone web app has the new shell (top bar, bottom bar, a More sheet) and sheets instead of the browser's boxes; results
  and errors appear in place; spools can be read and edited from the phone.
- The Android app draws in the new look: Settings, pairing, Home, Printers, One printer (progress, controls, loading a spool, mapping by loading), Spools, Add spools (Photos, Check the spools,
  Preview, Done), Recently added and the filament catalog line.

## Still in the old look or not finished

- Parts of the phone web app and the Android app, and any Hub page section that has not moved yet, still look as in 0.5.4.
- The command line keeps its 0.5.4 wording; its new wording and the theme picker are not in this release.

## Install it over 0.5.4

A pre-release is not the newest release, so `filament-kit update` does not find it. Install it by version, on the Ubuntu
computer:

```
curl -fsSLO https://github.com/thompsonfabco/filament-kit/releases/latest/download/get.sh && sudo bash get.sh --version 0.6.0
```

It keeps your spools, settings, key and paired phones. After it, `filament-kit update` says you are up to date until a newer release than this one comes out.

## Going back to 0.5.4

Run the same command with the earlier version:

```
sudo bash get.sh --version 0.5.4
```

Your spools and settings stay.
